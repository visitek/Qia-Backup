    Only change this when recovering an existing backup set on another machine. The UUID is the last path component shown on the Dashboard.

    Source

    APFS only

    Qia Backup snapshots this Mac's APFS data volume locally with tmutil, then uploads incremental content to S3. No external drive is required.

    Only these folders under the volume are backed up. Parent folders are kept for navigation.
    Pickers add a literal path. You can also type glob patterns. macOS metadata such as .DS_Store, .Spotlight-V100 and .fseventsd is always ignored.
    Restores the recommended included folders and cache exclusions.

    After the recent window, keep the newest backup from each day.
    After the daily window, keep the newest backup from each week.
    After the weekly window, keep the newest backup from each month.
